# LifeLang frontend
- единственный тип данных — 32-битное целое `int`;
- локальные переменные: `var x, y;` (по дефолту инициализируются 0), `var z = 42;`;
- двумерные массивы фиксированного размера: `var field[500, 500];`, доступ `field[x, y]`;
- функции: `func name(params) { ... }`, все возвращают `int`;
- C-подобные условные конструкции: `if (...) { ... } [else { ... }]`,
  `loop { ... }` (безусловный бесконечный цикл) и `loop (cond; step) { ... }`;
- арифметические операции: `+ - * / %`, операции сравнения `< <= > >= == !=`,
  логические операторы `&& || !`, постфиксный инкремент `x++`.

Встроенные функции и константа (реализованы в `sim.c`):

```c
int rand();
void put_pixel(int x, int y, int color);
void flush();
const int WHITE = 0x00FFFFFF;
```

Тестовые примеры находятся в файлах test_*.llang.
